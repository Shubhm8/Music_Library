🎵 Music Library – Microservices Based Application

A complete microservices-based Music Library System 
This application includes two roles with separate capabilities: User and Admin.

---

⭐ Features

👤 User Features
- User Registration, Login & Logout
- View list of all songs
- View detailed song information:
    - Name
    - Singer
    - Music Director
    - Release Date
    - Album Name
- Search songs by:
    - Name
    - Artist
    - Album
    - Music Director
- Create multiple playlists
- CRUD operations on:
    - Playlists
    - Songs inside playlists
- Search songs inside playlists
- Music player controls:
    - Play
    - Stop
    - Repeat
    - Shuffle
- View all playlists created by user

---

🛠️ Admin Features
- Admin Login & Logout
- Full CRUD on Songs
- Restrict song visibility for users
- Send notifications when new songs are added
- Manage entire song library

---

🧩 Microservices Architecture

📌 Includes:
- User Service – Login, Register, Playlist Management
- Admin Service – Song Management, Visibility Control
- Song Service – Song Metadata CRUD
- Notification Service – Sends email notifications
- Eureka Server – Service Discovery
